## ポイント

- ツール呼び出しを行う実験的なCode Modeを追加
- plugin.jsonによるバージョン制御や型チェック機能を導入
- 大規模ファイル編集時のメモリ急増など多数の不具合を修正

## 要約

Anthropicは、開発支援ツールの最新版となるClaude Code v2.1.323をリリースした。

今回のアップデートでは、ツール呼び出しにJavaScriptを使用する実験的機能「Code Mode」が追加された。また、plugin.jsonでのバージョン範囲指定や、TypeScriptフックモジュールの型チェック機能が導入されている。

さらに、大規模ファイルの編集時におけるメモリ急増問題や、バックグラウンドセッションに関する複数の不具合が修正された。
