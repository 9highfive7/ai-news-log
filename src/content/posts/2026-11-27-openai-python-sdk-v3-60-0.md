## ポイント

- OpenAI Python SDKのv3.60.0がリリースされた
- 支出アラートやセッションボールトの更新機能が追加された
- 音声ノイズ低減やバッチ処理などのドキュメントが整理された

## 要約

OpenAIは、Python SDKの最新バージョンであるv3.60.0を公開した。

今回のアップデートでは、API機能として支出アラート（spend alerts）やレスポンス圧縮フィールドの追加、セッション・ボールト（session vaults）の更新サポートが実装された。また、メッセージの再試行やバッチエンドポイント、リアルタイム音声のノイズ低減、メタデータ、インラインスキル・アップロードの制限に関するドキュメントの記述が明確化されている。

提供に関する追加の価格情報や制限事項は明記されていない。
