## ポイント

- AIによる開発支援ツール向けにクラウド専門知識を組み込むプラグインが公開された
- スキル定義やMCPサーバー設定をまとめて簡単に導入できる仕様を採用している
- クラウド環境に適合した正確なシステム構築をAIエージェント側で実行可能になる

## 要約

Google Cloudは、Claude Codeをはじめとする開発支援AIに対して、クラウド環境の専門知見や支援機能を統合する「Google Cloud Developer Plugin for AI Coding Agents」を公開した。本プラグインの導入により、AIエージェントはクラウドの公式ドキュメントやアーキテクチャの知見を参照できるようになる。

クラウドサービス固有のスキルセットやMCPサーバーの設定がパッケージ化されており、開発環境へ手軽に一括導入できる仕組みとなっている。これにより、AIがクラウド環境に最適化された正確なシステム構築やコード生成を行える環境が整う。
