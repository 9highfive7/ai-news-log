## ポイント

- MAI Code 2とMAI Code 2 Flashの2モデルを発表
- MAI Code 2は本番環境向けのコード生成やデバッグに対応
- MAI Code 2 Flashはルーチンワーク的な修正作業向けに設計

## 要約

マイクロソフトは年次イベント「Microsoft Ignite 2026」において、日常的なコーディング作業向けのAIモデル「MAI Code 2」と「MAI Code 2 Flash」を発表した。いずれも競合製品と同等の性能をより低コストで提供することを特徴としている。

MAI Code 2は本番環境のコード生成やデバッグ、UI構築などに適しており、主要なベンチマークの平均値で他社モデルの96〜98%の性能を発揮しつつ、コストは大幅に抑えられている。一方のMAI Code 2 Flashは、コードの解説やルーチンワーク的な修正などの大量の作業向けに設計されており、品質と徹底的な低コストを両立させている。
