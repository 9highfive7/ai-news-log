## ポイント

- GitHub Universe 2026でCopilot Fusionが正式に公開された
- タスクの性質に合わせて複数のAIモデルを自動で使い分ける仕組みを搭載している
- 用途やコストに合わせて4段階の負荷レベルやローカルモデルの選択が可能である

## 要約

GitHubは年次イベント「GitHub Universe 2026」の場において、マルチモデルに対応した「GitHub Copilot Fusion」の提供開始を明らかにした。

本機能は、コード生成やデバッグなどのタスク要求を分析し、最適な単一または複数のAIモデルを連動させる仕組みを持つ。処理パターンには単体実行の「Single」に加え、検証プロセスを挟む「Cascade」や、別モデルによるレビューと修正を行う「Critique」が用意されている。さらに、コストや品質の要件に応じて4段階の負荷レベルを選択できるほか、プレビュー段階としてローカルモデルの利用にも対応する。

開発者はAIの選定や管理の手間を省きつつ、処理性能とコスト効率を最適化させながら開発を進められる。
