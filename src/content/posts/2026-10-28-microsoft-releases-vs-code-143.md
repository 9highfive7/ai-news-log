## ポイント

- VS Code 1.143において初期セッションの標準機能がCopilotハーネスに移行
- 複数のAIモデルに同一タスクを並行処理させ結果を検証する機能を追加
- 対応デバイス上でローカル動作するMAI-Code-1.1-Flashモデルをサポート

## 要約

Microsoftはコードエディター「Visual Studio Code 1.143」をリリースし、新しいセッションの標準動作をCopilotハーネスへと移行した。Copilot SDKベースのこの仕組みにより、AIエージェントによるツール呼び出しやバックグラウンド処理の管理が統合される。

追加された機能には、同一のコーディング作業を複数のAIモデルで同時に処理させ、成果物を比較・統合するプレビュー機能が含まれる。さらに、特定のデバイス環境で動作する「MAI-Code-1.1-Flash」モデルの利用や、不要になったワークツリーのクリーンアップ機能なども実装された。

 Copilotハーネスのセッションは、エディター画面または専用ウィンドウ経由でバックグラウンド実行が可能である。ローカル環境でのAIモデル駆動には、指定のGPUスペックなどの動作要件が求められる。
